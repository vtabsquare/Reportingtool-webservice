# VTAB Reporting Services 6.1.8

Services-only maintenance release.

- Published slicer dropdown menus now escape the compact slicer body instead of being clipped inside it.
- The published visual wrapper reads dropdown mode from the saved visual format.
- PDF and PowerPoint first use the high-fidelity rendered-page export.
- If browser capture or rendered export fails, the viewer automatically retries through the server-side exporter.
- Direct server-side PDF/PPTX export now resolves cloud-published reports as well as locally stored reports.
- Existing role-based export restrictions remain enforced on both paths.

No Desktop files are included in this update.
